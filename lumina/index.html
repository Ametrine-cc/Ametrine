Lumina

Lumina | The video editor

GitHub Repo Download

Description of the project:

The video editing software made for everyone. Lumina was made to replace the current popular video editors like Adobe Premiere Pro and the cheap, subscription riddled ones like Capcut and allow everyone the chance to use a good editor for free, forever. Built to be robust and handle any workload thrown at it, Lumina is for both professional and beginners alike.

What can Lumina be installed on:

  • Linux
  • MacOS (Untested)
  • FreeBSD (Untested)
  • Windows 10/11 (Untested)

Installation:

To install Lumina, follow these steps:

  1. Clone the repository.
  2. Run the installation script.
  3. Enjoy using Lumina! 
git clone https://github.com/Ametrine-cc/Lumina.git
cd Lumina

chmod +x install.sh
./install.sh
