UV | The Learning API

GitHub Repo Download

Description of the project:

UV is a simple learning API for apps like brilliant and skillshare. UV has a desktop app and mobile app for basic use but developers can make their own connecting to the api to make the experience better for users.

What can UV be installed on:

  • Linux
  • MacOS (Untested)
  • FreeBSD (Untested)

Usage:

To use UV, follow these steps:

  1. Clone the repository.
  2. Run the installation script.
  3. Enjoy using uv! 
git clone https://github.com/Ametrine-cc/uv.git
cd uv

# To install uv server
chmod +x install_server.sh
./install_server.sh

# To install uv desktop
chmod +x install_desktop.sh
./install_desktop.sh
